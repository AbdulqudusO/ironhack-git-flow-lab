Short Reflection

1. What problem does Git Flow solve for teams?

Git Flow helped me understand how developers can work on different features and fixes without affecting the main project. During this lab, I used separate branches to develop the header banner, add the dark-mode button, and fix an accessibility issue. I also learned how Pull Requests help organize and review changes before merging them. I now understand why Git Flow is useful for teamwork, especially when multiple developers are working on the same project.

2. Which Git command did you find most useful and why?

The Git command I found most useful was git merge. It allowed me to combine changes from different branches into one project. One interesting challenge I encountered was a merge conflict in styles.css when I tried to merge the accessibility hotfix into develop. I had to review both versions of the code and carefully resolve the conflict without losing the dark-mode functionality. This experience helped me understand how Git handles conflicting changes and gave me more confidence in managing branches and merging code.
